增强 GitHub Desktop，
无需修改它本身

用官方 V8 Inspector 调试接口，在运行时注入增强逻辑：禁用更新、屏蔽遥测、中文界面、AI 提交信息、最近仓库置顶。Rust 内核，常驻内存目标 < 10MB。

Features

你需要的增强，都在这里

每一项都能在内嵌设置弹窗里开关，改动即时生效，不用重启 GitHub Desktop。

禁用自动更新

阻止 autoUpdater 检查与安装，并接管 About 里的"检查更新"按钮，保持你打了补丁的版本。

热生效

屏蔽遥测上报

拦截发往 central / usage / stats.github.com 的统计与异常上报，包装 GHD 自身的请求监听器，确保真正拦得住。

热生效

中文界面 (i18n)

菜单翻译 + DOM 文本替换实现界面中文化。语言包可导入、导出、切换，切换后界面自动刷新。

热生效

AI 提交信息

接管提交框的 Copilot 按钮，用任意 OpenAI 兼容接口生成提交信息。内置连通性测试，先验证再保存。

How it works

0-path 注入，不碰安装文件

GDP 不分发、不修改 GitHub Desktop，只在本机启动时通过官方调试接口注入增强逻辑。

1

以调试模式启动

Rust gdp 用 --inspect-brk=0 拉起 GitHub Desktop，进程在 main.js 执行前暂停。

2

注入 hook

通过 V8 Inspector (CDP) 连接，在主进程注入更新拦截、遥测屏蔽、菜单与渲染进程 i18n 等 hook。

3

IPC 驱动一切

配置、语言包、日志、AI 请求全部经 Electron IPC 在注入的 hook 内完成，不依赖本地 HTTP 服务。

Get started

三步跑起来

需要已安装 GitHub Desktop、Node.js 22+、pnpm 与 Rust 工具链。

bash 
# 1 · 克隆仓库
git clone https://github.com/sj817/github-desktop-plus
cd github-desktop-plus

# 2 · 安装依赖并构建（语言包 + hook + Rust 二进制）
pnpm install
pnpm run build

# 3 · 启动增强版 GitHub Desktop
gdp launch
