新增 macOS 支持，提供 Apple Silicon 和 Intel 两种架构的 DMG 与 ZIP 安装包。

- 将 **GitHub Desktop Plus.app** 拖入 Applications 即可启动，自动查找系统或用户 Applications 目录中的官方 GitHub Desktop；也支持通过命令行指定自定义 `.app` 路径。
- 适配 macOS 菜单汉化、`⌘⌥G` 设置快捷键和 `⌘S` 保存提示，修复 Option 键改变字符后快捷键不响应的问题。
- 「打开方式」支持系统和用户目录中的编辑器、JetBrains IDE、Terminal、iTerm2、Ghostty、Warp 等程序；打开文件时，终端会定位到文件所在目录。
- Plus 内置更新按当前架构下载 DMG，并在打开前校验 SHA-256；打开后将 Plus 拖入 Applications 替换，再重新启动。
- 修复 macOS 启动路径、平台构建依赖和退出后的守护进程回收；macOS 构建无需 Linux 交叉编译或 WSL。

macOS 需要 12 或更高版本，并预先安装官方 GitHub Desktop。配置保存在 `~/Library/Application Support/github-desktop-plus`，不修改官方应用文件。

本版 macOS 安装包使用临时签名，尚未经过 Apple 公证。Apple Silicon 已完成本机隔离启动、菜单与设置验证；Intel 由 CI 构建，尚未实机验证。

Windows 继续提供安装版和便携版。所有平台均附带 SHA-256 校验清单。
