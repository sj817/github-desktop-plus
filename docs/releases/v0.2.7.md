针对大型 diff、频繁切换仓库和内存积累的优化。

- 优化官方 diff 行数据构造，避免反复从 token 数组头部删除元素；保留统一视图和左右对照视图的内容、行号、行内高亮与选择数据。
- 汉化直接跳过代码子树，减少大型 diff 展示和滚动时的额外遍历。
- 切换仓库后释放非当前仓库的工作区 diff，保留提交草稿、文件勾选和部分行选择；切回后按需重新加载。
- 高亮限制为最多 2 个运行任务和 4 个等待任务，闲置 worker 30 秒后释放，并解除已完成任务的事件回调和输入引用。
- 阻止过时的仓库选择启动刷新；工作区 diff 只接受最新请求的结果，覆盖同文件连续修改及切走再切回的情况。
- renderer 补丁异步读取、合并并发加载并限制缓存；不兼容的源码结构保持官方实现，并记录诊断信息。

已验证本机官方 3.6.4、3.6.5 的补丁匹配、完整 bundle 语法和相关回归。隔离基准验证了大型 diff 组装加速及旧 diff 可回收；这些结果不代表整个应用的交互提速或实际 1–2 GB 场景的整体内存降幅。
